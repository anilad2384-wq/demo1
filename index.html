Within-domain comparisons

Text understanding

BERT → DistilBERT

Distillation reduces parameters from ~110M to ~66M. The original paper reports roughly 97% retained language understanding and 60% faster inference. Prefer DistilBERT for lower-cost classification; evaluate BERT when quality is paramount.

BERT 110M versus DistilBERT 66M parameters

Image classification

MobileNetV2 → EfficientNet-B0

Moving from MobileNetV2 to EfficientNet-B0 increases ImageNet top-1 accuracy from 71.878% to 77.692% while increasing operations from 0.30 to 0.39 GFLOPs/image.

Same benchmark, pinned TorchVision weights

Structured data

TabPFN v2: a different axis

TabPFN uses prior learning on synthetic tables and can predict on a new small dataset without conventional task-specific gradient training. Its reported 2.8-second experiment is not an inference-per-row speed or a fair cross-domain comparison.

Compare against LightGBM / XGBoost on the same tabular splits; these baselines are typically trained on the target data, not downloaded as universal pretrained checkpoints.

Explainability is not the same as accuracy. Attention maps, SHAP, LIME, feature importance and saliency maps can support analysis but are not guarantees of faithful causal explanations. Include subgroup error checks, robustness tests and human review for consequential decisions.
Research, decisions and reflection

How to choose a model

Research method: I chose five public, downloadable pretrained checkpoints representing three domains. Within each domain, I prioritized fixed model versions and source-reported benchmark results, recorded sizes and compute proxies, and labeled non-comparable measurements. For tabular data I chose TabPFN rather than calling XGBoost or Random Forest a universal pretrained model, because those are usually algorithms trained from scratch on a particular dataset.

NLP

Recommend DistilBERT for low-latency sentiment or intent classification. Choose BERT if repeatable task-specific testing supports the extra quality. Neither is an open-ended GPT-style generator.

Vision

Recommend MobileNetV2 for constrained mobile devices. Choose EfficientNet-B0 for better reference ImageNet accuracy when compute headroom exists.

Tabular

Trial TabPFN v2 for small datasets; compare against tuned gradient-boosting baselines for scale, deployment cost, interpretability and calibration.

Portfolio reflection

The central challenge was avoiding a misleading global leaderboard: quality metrics for sentiment classification, image recognition and tabular prediction measure different tasks. I addressed this by grouping models by application domain and displaying relative trade-offs only where metrics were comparable. I also learned to distinguish pretrained checkpoints from algorithms that require fitting on task-specific data, and to separate operational latency from FLOPs or end-to-end research timings. In future projects I would reproduce tests on identical hardware, report confidence intervals, check demographic and distribution shifts, and document explanation limitations.

Design rationale: color identifies the domain; the matrix aligns criteria side by side; three domain cards explain relationships; the five-step sequence turns the research into a reusable evaluation workflow. Semantic headings, meaningful labels, keyboard focus and mobile scroll support accessibility.
